# P1-1 统一执行模式审查

## 范围

- 分支：`feat/d0-tdd-collaboration-infra`
- 阶段：P1-1 demo / dry-run / real-run 标签、确认弹窗和执行进度
- 日期：2026-05-29
- 监督者：Hypatia（只读审查）

## 交付内容

- 后端新增 `ExecuteMode` 枚举，`ExecuteRequest` 增加 `mode`、`confirmed`。
- 后端 `ExecuteResult` 增加 `execution_mode`、`steps`、`warnings`。
- `demo` / `dry_run` 统一走预览路径，返回步骤，不调用真实下单服务。
- `real` 未确认时由后端阻断。
- Polymarket / Options 的实盘路径在本阶段明确阻断，避免未完成能力被误当成实盘闭环。
- 前端新增 `ExecutionModeSwitch`，顶部始终可切换执行模式。
- 前端新增 `ConfirmExecutionModal`，`real` 模式必须勾选确认。
- 前端新增 `ExecutionProgress`，执行中和执行完成后展示步骤。
- `HedgeCard` 改为先确认再执行，并在 payload 中带 `mode` 与 `confirmed`。
- 审查后补强：dry-run 结果使用独立视觉 tone；Options real 阻断补测；Reverse real confirmed 正向调用补测；real 前端确认 payload 补测。
